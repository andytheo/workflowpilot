# Affiliate program onboarding checklist

1. Publish helpful, accurate content and a clear disclosure page.
2. Create a dedicated business contact address and add it to the website.
3. Read each program's geographic eligibility, payout threshold, tax, trademark, paid advertising and social media policies.
4. Apply on the official program website. Never enter credentials or payment details into an unverified form.
5. Store your approved tracking links privately until ready to publish. Do not commit affiliate credentials, API keys or private tax information to GitHub.
6. Replace ordinary provider links only when you have approval and a working tracking URL.
7. Mark each commercial link with a nearby disclosure and `rel="sponsored noopener noreferrer"`.
8. Test outbound links and review analytics monthly.
